Install and run using Python 3.11:

`powershell
$py311 = 'C:\Users\Admin\AppData\Local\Programs\Python\Python311\python.exe'
$pip311 = 'C:\Users\Admin\AppData\Local\Programs\Python\Python311\Scripts\pip.exe'

Set-Location 'C:\Users\Admin\riko_project'
# (dependencies are typically installed for 3.11 already)
& $pip311 install -r requirements.txt
& $pip311 install -r extra-req.txt  # optional

# Run the assistant
& $py311 server/main_chat.py
`

Notes:
- Ensure GPT-SoVITS is running at http://127.0.0.1:9880 before launching (the assistant POSTs to /tts).
- To use the local opencode CLI backend, set llm_provider: opencode in character_config.yaml and ensure opencode is on your PATH.
